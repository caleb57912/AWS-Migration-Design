# Modules

| Module | Builds |
|---|---|
| `network` | VPC, subnet tiers across two AZs, NAT, route tables, VPC endpoints |
| `security` | KMS keys, security groups, CloudTrail, GuardDuty, Config |
| `identity` | IAM roles and instance profiles |
| `compute` | Launch template, Auto Scaling group, Application Load Balancer |
| `database` | RDS PostgreSQL, subnet group, Secrets Manager credentials |
| `storage` | S3 buckets with encryption, versioning, lifecycle, Block Public Access |
| `imaging` | AWS HealthImaging data store |
| `monitoring` | CloudWatch alarms, SNS topic, budget alerts |
